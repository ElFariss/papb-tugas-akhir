# Contributing

1. `scripts/git/setup.sh` once after cloning.
2. `git switch -c <role>/<type>-<description> origin/main`
3. Work in your own module only: [ownership map](contracts/ownership.map).
4. `scripts/git/push.sh`, then open a pull request.

Full rules: [Git contract](docs/contracts/GIT_CONTRACT.md) and [module contracts](docs/contracts/MODULE_CONTRACTS.md).
